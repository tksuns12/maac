under [the instrument gain contract](instrument-gain.md). Astra Low executed
this final validation package against base
`c7317a3c5f5b5c7616beb53a2e53f112b6ede890` plus the current instrument-gain
source/test/example changes. User compositions were preserved.

Environment: macOS 26.6.2 arm64, Rust 1.95.0 (`59807616e`), Cargo 1.95.0
(`f2d3ce0bd`). All execution used local synthetic audio without network access
or production interaction. No dependencies were added.

## Fresh installed CLI

The fresh installed binary ran outside the checkout in an isolated
`/private/tmp` directory. The checked-in stereo example and a self-contained
custom mono fixture from `tests/instrument_gain_cli.rs` each passed source
check, compile, and direct builds in Float32 and PCM16. Source deletion preceded
retained-plan rendering and a second render in each encoding.

For both fixtures and both encodings, direct-build, retained-render, and repeated
render WAV bytes and SHA-256 hashes matched. Every WAV was finite and contained
nonzero samples. Float32 headers reported format 3 / 32 bits and PCM16 headers
format 1 / 16 bits. All outputs were 48 kHz; the example was stereo with 91,200
frames and the custom fixture mono with 2,880 frames.

Three additional installed-binary failure cases exercised negative gain,
exponential zero, and valid positive gain producing PCM16 overload. The first
two returned `E_RANGE`, and overload returned `E_PCM16_RANGE`; every failed
`build --format pcm16 --force` preserved the pre-existing output bytes.

`installed_probe.py` is the reproducible scenario script. `installed-probe.json`
records arguments, working directory, exit statuses (including expected
failures), timings, headers, and hashes. Plans and WAVs remain in the evidence
directory. The temporary execution directory was removed.

The existing acceptance script freshly installed the current release into its
standard `target/install` root and passed all 38 legacy checks. Its full result
is copied to `legacy-acceptance-results.json`; detailed artifacts remain under
`target/acceptance/`. `delivery-commands.json` records both Python command exits
and elapsed times.
